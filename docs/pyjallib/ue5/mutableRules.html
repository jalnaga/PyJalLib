pyjallib.ue5.mutableRules

Mutable Customizable Object 생성 계획 결정 (unreal 비의존 순수 로직)

캐릭터 폴더의 스켈레탈 메쉬 목록을 받아 "어떤 CO를 어디에 무슨 이름으로 만들고, 템플릿의 어느 노드를 어느 메쉬/매테리얼/그룹으로 바꿀지"만 결정한다. 에셋을 복제하고 노드를 고치는 일은 inUnreal/mutableObjects.py가 하고, 이 모듈은 그 결정을 한 곳에 모은다.

이 모듈은 표준 라이브러리만 쓴다 - 편의가 아니라 요구사항이다. UE5 임베디드 파이썬에는 pyjallib 전체가 import되지 않으므로(pyjallib/__init__이 P4Python을 끌어온다), 인-UE5 어댑터와 콘솔 테스트가 같은 결정 함수를 쓰려면 이 모듈이 stdlib만 의존해야 한다.

폴더 규약 (호출자가 MutableBuildConfig로 주입한다 - 프로젝트 규약은 상수로 두지 않는다):

{characterRoot}/{meshFolder}/{outfit}/{slot}/{meshPrefix}{character}_{role}_{outfit}_{slot}
{characterRoot}/{mutableFolder}/{baseAssetName}          <- Base CO
{characterRoot}/{meshFolder}/{outfit}/{slot}/{objectPrefix}{character}_{role}_{outfit}_{slot}
                                                          <- 슬롯 CO (메쉬와 같은 폴더)

노드 식별 규칙 (2026-10-16 실측):

  • Python에서 Component 이름·노드 핀 연결은 보이지 않는다. 그래서 템플릿이 노드마다 박아 둔 플레이스홀더 메쉬/매테리얼 값을 식별자로 쓴다.
  • 플레이스홀더 메쉬 이름의 마지막 _ 토큰이 부품명이다(..._Default_Body -> Body).
  • 템플릿 SK 노드가 1개면 그 노드는 슬롯 메쉬로 바꾼다(단일 SK 템플릿은 플레이스홀더가 슬롯과 무관하게 같을 수 있으므로 토큰을 쓰지 않는다). 여러 개면 부품명으로 같은 외형의 형제 폴더 메쉬를 찾고, 하나라도 없으면 그 CO는 만들지 않는다(fail-closed).
  • Mesh Section 매테리얼은 "플레이스홀더 매테리얼이 플레이스홀더 메쉬의 몇 번째 슬롯인가"를 찾아 새 메쉬의 같은 인덱스 매테리얼로 바꾼다.
  • 그룹 GUID는 Base 그룹 노드의 T3D 익스포트 텍스트에서 읽는다(복제 시 그래프 노드 GUID가 전부 재생성되고 NodeGuid는 Python에서 읽히지 않는다).

매칭이 0건이거나 2건 이상이면 추측하지 않고 실패 사유를 남긴다.

107@dataclass(frozen=True)
108class MutableBuildConfig:
109    """CO 생성 규약. 프로젝트 규약 값은 전부 호출자가 넣는다(기본값 없음).
110
111    Attributes:
112        baseTemplatePath: Base CO 템플릿 패키지 경로
113        slotTemplatePattern: 슬롯 템플릿 패키지 경로 형식. `{slot}` 자리표시자 필수.
114        meshFolderName: 캐릭터 루트 아래 메쉬 폴더 이름
115        mutableFolderName: 캐릭터 루트 아래 Base CO를 둘 폴더 이름
116        baseOutfit: Base CO의 Component 메쉬를 가져올 외형 이름
117        excludedOutfits: 슬롯 CO를 만들지 않을 외형 이름들
118        meshPrefix: 스켈레탈 메쉬 에셋 이름 접두
119        objectPrefix: CO 에셋 이름 접두(슬롯 CO 이름 = 메쉬 이름의 접두만 바꾼 것)
120        baseAssetNameFormat: Base CO 에셋 이름 형식. `{character}` `{role}` 사용 가능.
121        baseObjectNameFormat: Base CO의 Base Object 노드 이름 형식. `{character}` `{role}`.
122        slotObjectNameFormat: 슬롯 CO의 Base Object 노드 이름 형식.
123            `{character}` `{role}` `{outfit}` `{slot}` 사용 가능.
124    """
125
126    baseTemplatePath: str
127    slotTemplatePattern: str
128    meshFolderName: str
129    mutableFolderName: str
130    baseOutfit: str
131    excludedOutfits: Tuple[str, ...] = ()
132    meshPrefix: str = "SK_"
133    objectPrefix: str = "CO_"
134    baseAssetNameFormat: str = "{objectPrefix}{character}_{role}_Base"
135    baseObjectNameFormat: str = "{character}_{role}"
136    slotObjectNameFormat: str = "{outfit}"
137
138    def validate(self) -> None:
139        """설정이 결정을 내릴 수 있는 상태인지 확인한다.
140
141        Raises:
142            MutableConfigError: 필수 값이 비었거나 형식 자리표시자가 없음
143        """
144        required = {
145            "baseTemplatePath": self.baseTemplatePath,
146            "slotTemplatePattern": self.slotTemplatePattern,
147            "meshFolderName": self.meshFolderName,
148            "mutableFolderName": self.mutableFolderName,
149            "baseOutfit": self.baseOutfit,
150            "meshPrefix": self.meshPrefix,
151            "objectPrefix": self.objectPrefix,
152        }
153        empty = [name for name, value in required.items() if not value]
154        if empty:
155            raise MutableConfigError(f"필수 설정이 비었다: {', '.join(empty)}")
156        if "{slot}" not in self.slotTemplatePattern:
157            raise MutableConfigError("slotTemplatePattern에 {slot} 자리표시자가 없다")

161
162        Args:
163            inSlot: 슬롯 이름
164
165        Returns:
166            패키지 경로
167        """
168        return self.slotTemplatePattern.format(slot=inSlot)

257def to_package_path(inPath: str) -> str:
258    """오브젝트 경로(`/Game/A/B.B`)를 패키지 경로(`/Game/A/B`)로 바꾼다.
259
260    `.` 절단은 마지막 `/` 뒤 세그먼트에만 한다 - 폴더명에 `.`이 있으면 경로 중간이 잘린다.
261    끝의 `/`도 떼어 낸다.
262
263    Args:
264        inPath: 패키지 또는 오브젝트 경로
265
266    Returns:
267        패키지 경로
268    """
269    text = str(inPath).strip().rstrip("/")
270    head, separator, tail = text.rpartition("/")
271    if "." in tail:
272        tail = tail.split(".", 1)[0]
273    return f"{head}{separator}{tail}"

300def parse_mesh_role(inMeshName: str, inCharacter: str, inOutfit: str, inSlot: str, inMeshPrefix: str) -> Optional[str]:
301    """`{prefix}{character}_{role}_{outfit}_{slot}`에서 역할 약어를 읽는다.
302
303    `_`로 쪼개지 않는다 - 캐릭터 이름에 `_`가 있을 수 있다(`Hero_test`). 폴더에서 아는
304    토큰을 앞뒤로 맞추고 가운데를 역할 약어로 읽는다.
305
306    Args:
307        inMeshName: 메쉬 에셋 이름
308        inCharacter: 캐릭터 이름(루트 폴더명)
309        inOutfit: 외형 이름(폴더명)
310        inSlot: 슬롯 이름(폴더명)
311        inMeshPrefix: 메쉬 접두
312
313    Returns:
314        역할 약어. 형식이 맞지 않으면 None.
315    """
316    prefix = f"{inMeshPrefix}{inCharacter}_"
317    suffix = f"_{inOutfit}_{inSlot}"
318    if not (inMeshName.startswith(prefix) and inMeshName.endswith(suffix)):
319        return None
320    if len(inMeshName) <= len(prefix) + len(suffix):
321        return None
322    role = inMeshName[len(prefix):len(inMeshName) - len(suffix)]
323    if not role or "_" in role:
324        return None
325    return role

364def _classify_meshes(
365    inRoot: str, inCharacter: str, inMeshPaths: Sequence[str], inConfig: MutableBuildConfig
366) -> Tuple[Dict[str, Dict[str, List[str]]], List[Tuple[str, str]]]:
367    """메쉬 경로를 {외형: {슬롯: [경로...]}}로 묶고 대상 밖은 사유와 함께 뺀다.
368
369    Args:
370        inRoot: 캐릭터 루트(패키지 경로)
371        inCharacter: 캐릭터 이름
372        inMeshPaths: 캐릭터 루트 아래 스켈레탈 메쉬 경로 목록
373        inConfig: 생성 규약
374
375    Returns:
376        (외형별 슬롯 메쉬, 제외 목록)
377    """
378    meshRoot = f"{inRoot}/{inConfig.meshFolderName}/"
379    grouped: Dict[str, Dict[str, List[str]]] = {}
380    ignored: List[Tuple[str, str]] = []
381    for rawPath in inMeshPaths:
382        path = to_package_path(rawPath)
383        if not path.startswith(meshRoot):
384            ignored.append((path, IGNORED_OUTSIDE_MESH_FOLDER))
385            continue
386        parts = path[len(meshRoot):].split("/")
387        if len(parts) != 3:
388            ignored.append((path, IGNORED_NOT_SLOT_MESH))
389            continue
390        outfit, slot, name = parts
391        if not name.startswith(inConfig.meshPrefix):
392            ignored.append((path, IGNORED_NOT_MESH_PREFIX))
393            continue
394        if outfit in inConfig.excludedOutfits:
395            ignored.append((path, IGNORED_EXCLUDED_OUTFIT))
396            continue
397        grouped.setdefault(outfit, {}).setdefault(slot, []).append(path)
398    return grouped, ignored

401def build_character_plan(
402    inCharacterRoot: str,
403    inMeshPaths: Sequence[str],
404    inExistingPaths: Sequence[str],
405    inTemplateSlots: Sequence[str],
406    inConfig: MutableBuildConfig,
407) -> CharacterPlan:
408    """캐릭터 1명의 CO 생성 계획을 세운다(바인딩은 템플릿을 읽은 뒤 채운다).
409
410    Args:
411        inCharacterRoot: 캐릭터 루트 패키지 폴더(`/Game/.../{Role}/{Character}`)
412        inMeshPaths: 루트 아래 스켈레탈 메쉬 경로 목록
413        inExistingPaths: 이미 있는 에셋 경로 목록(대상 CO 존재 판정용)
414        inTemplateSlots: 슬롯 템플릿이 실제로 있는 슬롯 이름들
415        inConfig: 생성 규약
416
417    Returns:
418        계획
419
420    Raises:
421        MutableConfigError: 설정이 비었거나 형식이 틀림
422    """
423    inConfig.validate()
424    root = to_package_path(inCharacterRoot)
425    character = root.rsplit("/", 1)[-1]
426    existing = {to_package_path(path) for path in inExistingPaths}
427    templateSlots = set(inTemplateSlots)
428    grouped, ignored = _classify_meshes(root, character, inMeshPaths, inConfig)
429
430    roles = set()
431    slotEntries: List[Tuple[str, str, str, Optional[str], str]] = []
432    noTemplate: List[Tuple[str, str, str]] = []
433    for outfit in sorted(grouped):
434        for slot in sorted(grouped[outfit]):
435            paths = sorted(grouped[outfit][slot])
436            meshPath = paths[0]
437            role = parse_mesh_role(asset_name(meshPath), character, outfit, slot, inConfig.meshPrefix)
438            if role is not None:
439                roles.add(role)
440            if slot not in templateSlots:
441                noTemplate.append((outfit, slot, meshPath))
442                continue
443            if len(paths) > 1:
444                slotEntries.append((outfit, slot, meshPath, role, FAILED_MULTIPLE_MESHES))
445            elif role is None:
446                slotEntries.append((outfit, slot, meshPath, role, FAILED_NAME_MISMATCH))
447            else:
448                slotEntries.append((outfit, slot, meshPath, role, STATUS_PENDING))
449
450    characterRole = next(iter(roles)) if len(roles) == 1 else ""
451    basePartMeshes = {
452        slot: sorted(paths)[0]
453        for slot, paths in grouped.get(inConfig.baseOutfit, {}).items()
454    }
455    base = BaseObjectPlan(
456        assetPath=base_object_asset_path(root, character, characterRole or "{role}", inConfig),
457        objectName=inConfig.baseObjectNameFormat.format(character=character, role=characterRole or "{role}"),
458        templatePath=inConfig.baseTemplatePath,
459        partMeshes=basePartMeshes,
460    )
461    if len(roles) > 1:
462        base.status = FAILED_ROLE_MISMATCH
463        base.detail = f"메쉬 이름의 역할 약어가 여러 개다: {', '.join(sorted(roles))}"
464    elif not roles:
465        base.status = FAILED_NAME_MISMATCH
466        base.detail = "규약에 맞는 메쉬 이름이 없어 역할 약어를 읽지 못했다"
467    elif base.assetPath in existing:
468        base.status = STATUS_SKIPPED_EXISTS
469        base.detail = "기존 Base CO를 슬롯의 Parent로 재사용한다"
470    elif not basePartMeshes:
471        base.status = FAILED_MISSING_BASE_MESH
472        base.detail = f"기준 외형 '{inConfig.baseOutfit}'의 메쉬가 없다"
473
474    plan = CharacterPlan(characterRoot=root, character=character, role=characterRole, base=base,
475                         noTemplate=noTemplate, ignored=ignored)
476    for outfit, slot, meshPath, role, status in slotEntries:
477        meshName = asset_name(meshPath)
478        folder = meshPath.rsplit("/", 1)[0]
479        slotPlan = SlotObjectPlan(
480            outfit=outfit,
481            slot=slot,
482            meshPath=meshPath,
483            assetPath=f"{folder}/{slot_object_asset_name(meshName, inConfig)}",
484            objectName=inConfig.slotObjectNameFormat.format(
485                character=character, role=role or characterRole, outfit=outfit, slot=slot
486            ),
487            templatePath=inConfig.slot_template_path(slot),
488            outfitPartMeshes={name: sorted(paths)[0] for name, paths in grouped[outfit].items()},
489            status=status,
490        )
491        if status == FAILED_MULTIPLE_MESHES:
492            slotPlan.detail = f"슬롯 폴더에 메쉬가 여러 개다: {', '.join(sorted(grouped[outfit][slot]))}"
493        elif status == FAILED_NAME_MISMATCH:
494            slotPlan.detail = f"메쉬 이름이 규약과 다르다: {meshName}"
495        elif slotPlan.assetPath in existing:
496            slotPlan.status = STATUS_SKIPPED_EXISTS
497            slotPlan.detail = "대상 CO가 이미 있다"
498        elif base.status not in (STATUS_PENDING, STATUS_SKIPPED_EXISTS):
499            slotPlan.status = FAILED_BASE_UNAVAILABLE
500            slotPlan.detail = f"Base CO를 쓸 수 없다({base.status})"
501        plan.slots.append(slotPlan)
502    return plan

525def resolve_component_bindings(inPlaceholders: Sequence[str], inBasePartMeshes: Mapping[str, str]) -> BindingResult:
526    """Base 템플릿 Component의 플레이스홀더를 기준 외형 메쉬로 바인딩한다.
527
528    Args:
529        inPlaceholders: Component 노드 순서의 플레이스홀더 메쉬 경로
530        inBasePartMeshes: 기준 외형의 {부품 이름: 메쉬 경로}
531
532    Returns:
533        바인딩 결과
534    """
535    if not inPlaceholders:
536        return BindingResult([], FAILED_TEMPLATE_INVALID, "Base 템플릿에 Component 노드가 없다")
537    parts = [placeholder_part(path) for path in inPlaceholders]
538    duplicated = sorted({part for part in parts if parts.count(part) > 1})
539    if duplicated:
540        return BindingResult([], FAILED_PLACEHOLDER_AMBIGUOUS, f"부품명이 겹친다: {', '.join(duplicated)}")
541    missing = [part for part in parts if part not in inBasePartMeshes]
542    if missing:
543        return BindingResult([], FAILED_MISSING_BASE_MESH, f"기준 외형에 없는 부품: {', '.join(missing)}")
544    return BindingResult([(path, inBasePartMeshes[part]) for path, part in zip(inPlaceholders, parts)])

547def resolve_mesh_bindings(
548    inPlaceholders: Sequence[str], inSlot: str, inSlotMesh: str, inOutfitPartMeshes: Mapping[str, str]
549) -> BindingResult:
550    """슬롯 템플릿 SK 노드의 플레이스홀더를 새 메쉬로 바인딩한다.
551
552    Args:
553        inPlaceholders: SK 노드 순서의 플레이스홀더 메쉬 경로
554        inSlot: 슬롯 이름
555        inSlotMesh: 슬롯 메쉬 경로
556        inOutfitPartMeshes: 같은 외형의 {슬롯 폴더 이름: 메쉬 경로}
557
558    Returns:
559        바인딩 결과
560    """
561    if not inPlaceholders:
562        return BindingResult([], FAILED_TEMPLATE_INVALID, "슬롯 템플릿에 Skeletal Mesh 노드가 없다")
563    if len(inPlaceholders) == 1:
564        return BindingResult([(inPlaceholders[0], inSlotMesh)])
565    parts = [placeholder_part(path) for path in inPlaceholders]
566    duplicated = sorted({part for part in parts if parts.count(part) > 1})
567    if duplicated:
568        return BindingResult([], FAILED_PLACEHOLDER_AMBIGUOUS, f"부품명이 겹친다: {', '.join(duplicated)}")
569    if inSlot not in parts:
570        return BindingResult([], FAILED_PLACEHOLDER_AMBIGUOUS, f"플레이스홀더에 슬롯 자신('{inSlot}')이 없다")
571    bindings: List[Tuple[str, str]] = []
572    missing: List[str] = []
573    for path, part in zip(inPlaceholders, parts):
574        target = inSlotMesh if part == inSlot else inOutfitPartMeshes.get(part)
575        if target is None:
576            missing.append(part)
577        else:
578            bindings.append((path, target))
579    if missing:
580        return BindingResult([], FAILED_MISSING_PART_MESH, f"같은 외형에 없는 부품 메쉬: {', '.join(missing)}")
581    return BindingResult(bindings)

584def resolve_material_bindings(
585    inSectionMaterials: Sequence[str],
586    inPlaceholderMeshMaterials: Mapping[str, Sequence[Optional[str]]],
587    inMeshBindings: Sequence[Tuple[str, str]],
588    inTargetMeshMaterials: Mapping[str, Sequence[Optional[str]]],
589) -> BindingResult:
590    """Mesh Section의 플레이스홀더 매테리얼을 새 메쉬의 같은 인덱스 매테리얼로 바인딩한다.
591
592    Args:
593        inSectionMaterials: Mesh Section 노드 순서의 플레이스홀더 매테리얼 경로
594        inPlaceholderMeshMaterials: {플레이스홀더 메쉬: 매테리얼 슬롯 순서의 매테리얼 경로}
595        inMeshBindings: 메쉬 바인딩 [(플레이스홀더 메쉬, 새 메쉬)]
596        inTargetMeshMaterials: {새 메쉬: 매테리얼 슬롯 순서의 매테리얼 경로}
597
598    Returns:
599        바인딩 결과
600    """
601    # 비교는 패키지 경로로 하고, 돌려주는 새 매테리얼은 입력 원문 그대로 둔다(어댑터가 그 값으로 로드한다)
602    meshByPlaceholder = {to_package_path(src): to_package_path(dst) for src, dst in inMeshBindings}
603    placeholderMaterials = {to_package_path(k): [to_package_path(m) if m else None for m in v]
604                            for k, v in inPlaceholderMeshMaterials.items()}
605    targetMaterials = {to_package_path(k): list(v) for k, v in inTargetMeshMaterials.items()}
606    bindings: List[Tuple[str, str]] = []
607    for sectionMaterial in inSectionMaterials:
608        key = to_package_path(sectionMaterial) if sectionMaterial else None
609        hits = [
610            (meshPath, index)
611            for meshPath, materials in placeholderMaterials.items()
612            if meshPath in meshByPlaceholder
613            for index, material in enumerate(materials)
614            if key is not None and material == key
615        ]
616        if len(hits) != 1:
617            code = FAILED_MATERIAL_MISSING if not hits else FAILED_PLACEHOLDER_AMBIGUOUS
618            return BindingResult([], code, f"플레이스홀더 매테리얼 매칭 {len(hits)}건: {sectionMaterial}")
619        meshPath, index = hits[0]
620        newMaterials = targetMaterials.get(meshByPlaceholder[meshPath], [])
621        if index >= len(newMaterials) or not newMaterials[index]:
622            return BindingResult(
623                [], FAILED_MATERIAL_MISSING,
624                f"새 메쉬 {meshByPlaceholder[meshPath]}에 매테리얼 슬롯 {index}이 없다",
625            )
626        bindings.append((sectionMaterial, newMaterials[index]))
627    return BindingResult(bindings)

676def parse_t3d_objects(inText: str) -> List[T3DObject]:
677    """T3D 익스포트 텍스트를 객체 목록으로 읽는다.
678
679    `Begin Object` / `End Object` 중첩을 따라가며 각 객체의 **직속** `Key=Value` 줄만
680    그 객체에 붙인다(하위 객체 줄은 섞지 않는다). 객체 하나를 익스포트하면 클래스와 속성이
681    한 블록에 오고, 에셋 전체를 익스포트하면 1패스(`Class=`만)와 2패스(`ExportPath`와 속성)로
682    나뉘므로 같은 경로의 블록을 병합한다(2026-10-16 프로브 실측 형식). 클래스는 `Class=`가
683    없으면 `ExportPath`에서 읽는다. `CustomProperties` 줄(핀)은 속성이 아니므로 버린다.
684
685    Args:
686        inText: T3D 텍스트
687
688    Returns:
689        객체 목록(처음 나타난 순서)
690    """
691    objects: Dict[str, T3DObject] = {}
692    order: List[str] = []
693    stack: List[T3DObject] = []
694    for line in inText.splitlines():
695        beginMatch = _BEGIN_OBJECT.match(line)
696        if beginMatch:
697            rest = beginMatch.group("rest")
698            classMatch = _CLASS_ATTR.search(rest)
699            nameMatch = _NAME_ATTR.search(rest)
700            exportMatch = _EXPORT_PATH_ATTR.search(rest)
701            classPath = classMatch.group("cls") if classMatch else (exportMatch.group("cls") if exportMatch else "")
702            name = nameMatch.group("name") if nameMatch else ""
703            key = exportMatch.group("path") if exportMatch else name
704            obj = objects.get(key)
705            if obj is None:
706                obj = T3DObject(className=classPath.rsplit(".", 1)[-1], name=name, path=key)
707                objects[key] = obj
708                order.append(key)
709            elif not obj.className and classPath:
710                obj.className = classPath.rsplit(".", 1)[-1]
711            stack.append(obj)
712            continue
713        if _END_OBJECT.match(line):
714            if stack:
715                stack.pop()
716            continue
717        if not stack or line.lstrip().startswith("CustomProperties"):
718            continue
719        propMatch = _PROPERTY_LINE.match(line)
720        if propMatch:
721            stack[-1].props.setdefault(propMatch.group("key"), propMatch.group("value"))
722    return [objects[key] for key in order]

725def read_t3d_property(inText: str, inClassName: str, inPropName: str) -> List[str]:
726    """T3D 텍스트에서 특정 클래스 객체들의 속성 값(따옴표 해제)을 모은다.
727
728    Python에서 protected라 `get_editor_property`로 못 읽는 속성(`ObjectName`, `ComponentName`,

610        hits = [

612            for meshPath, materials in placeholderMaterials.items()
613            if meshPath in meshByPlaceholder
614            for index, material in enumerate(materials)
615            if key is not None and material == key
616        ]
617        if len(hits) != 1:

619            return BindingResult([], code, f"플레이스홀더 매테리얼 매칭 {len(hits)}건: {sectionMaterial}")
620        meshPath, index = hits[0]
621        newMaterials = targetMaterials.get(meshByPlaceholder[meshPath], [])
622        if index >= len(newMaterials) or not newMaterials[index]:
623            return BindingResult(
624                [], FAILED_MATERIAL_MISSING,
625                f"새 메쉬 {meshByPlaceholder[meshPath]}에 매테리얼 슬롯 {index}이 없다",
626            )
627        bindings.append((sectionMaterial, newMaterials[index]))
628    return BindingResult(bindings)

691    """

693    order: List[str] = []
694    stack: List[T3DObject] = []
695    for line in inText.splitlines():
696        beginMatch = _BEGIN_OBJECT.match(line)
697        if beginMatch:
698            rest = beginMatch.group("rest")
699            classMatch = _CLASS_ATTR.search(rest)
700            nameMatch = _NAME_ATTR.search(rest)
701            exportMatch = _EXPORT_PATH_ATTR.search(rest)
702            classPath = classMatch.group("cls") if classMatch else (exportMatch.group("cls") if exportMatch else "")
703            name = nameMatch.group("name") if nameMatch else ""
704            key = exportMatch.group("path") if exportMatch else name
705            obj = objects.get(key)
706            if obj is None:
707                obj = T3DObject(className=classPath.rsplit(".", 1)[-1], name=name, path=key)
708                objects[key] = obj
709                order.append(key)
710            elif not obj.className and classPath:
711                obj.className = classPath.rsplit(".", 1)[-1]
712            stack.append(obj)
713            continue
714        if _END_OBJECT.match(line):
715            if stack:
716                stack.pop()
717            continue
718        if not stack or line.lstrip().startswith("CustomProperties"):
719            continue
720        propMatch = _PROPERTY_LINE.match(line)
721        if propMatch:
722            stack[-1].props.setdefault(propMatch.group("key"), propMatch.group("value"))
723    return [objects[key] for key in order]
