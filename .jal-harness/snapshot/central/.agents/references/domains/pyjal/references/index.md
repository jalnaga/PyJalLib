# 원문과 추적성

- [원문 이전 범위와 추적성](migration.md): 기술 원문의 출처와 개념 대응.
- [현재 보존·제거 범위](../guides/legacy-compatibility.md): 0.5.7 운영 기준과 구 운영 사본 정리.
- [원문 manifest](manifest.json): 유지한 기술 원문의 해시와 제거한 운영 사본의 고정 Git 출처.

구 설치·이전 검증 JSON은 현재 트리에서 제거했다. 현재 설치 결과는 설치된 0.5.7 플러그인의 doctor와 knowledge-check로 확인한다. 과거 검증 원문은 manifest에 기록한 삭제 전 커밋의 references 디렉터리에서 확인할 수 있다.
