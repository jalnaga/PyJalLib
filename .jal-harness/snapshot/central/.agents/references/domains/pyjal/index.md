## 상태와 배포 범위

기술 문서는 원문 관측을 이전한 초안이며 현재 DCC에서 재실행 검증한 API 보증서가 아니다. 프로젝트 카드는 설정 스냅샷이다. `verified`가 없는 문서에 검증 완료를 추정하지 않는다. ORV 내부 사례가 포함된 전체 번들은 내부 자료로 취급한다. 공개 라이브러리 문서를 만들 때는 [공개 범위](guides/publication-scope.md)를 적용한다.
