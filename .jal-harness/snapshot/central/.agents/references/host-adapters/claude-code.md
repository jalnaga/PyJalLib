# Claude Code 단독 어댑터

근거: [Agent teams 공식 문서](https://code.claude.com/docs/en/agent-teams). Agent teams는 실험 기능이며 기본 활성화를 가정하지 않는다. 팀원은 별도 전체 세션이고 메시지·공유 작업 목록과 직접 대화를 제공한다. 이번 작업에서는 Claude 실행을 실증하지 않았다.

코디네이터가 Git으로 worktree를 만들고 setup·지시서·exclude·공용 안내를 준비한다. 작업공간 생성과 agent 시작이 결합된 isolation 방식은 지시서 준비 전 작업하지 않는 대기를 실증하기 전에는 사용하지 않는다. 팀원을 특정 worktree에서 시작하는 방법과 실제 cwd·프로젝트 지침 적용은 설치 버전 문서와 임시 환경에서 확인해야 한다.

팀 기능이 지원되면 코디네이터가 테스터 팀원을 실행하고 메시지와 공식 종료 확인 후 같은 위치에 별도 구현자를 시작한다. 팀원이 중간 코디네이터나 추가 팀원을 생성하지 않도록 배정한다. 팀이 없고 필요한 별도 세션 생성 도구도 없으면 사용자가 작업 폴더에서 `claude`를 실행하고 지시서를 첫 메시지로 전달하는 반자동 흐름을 사용한다.

팀 질문은 리드에게 전달하고 개입형은 사용자와 직접 대화한다. named subagent 메시지 등 지원은 버전별로 달라질 수 있으므로 서브 에이전트가 항상 질문할 수 없다고 단정하지 않는다. 직접 채널이 없는 방식은 질문·현재 변경·재개 정보 반환 후 종료하고 답변을 포함해 재실행한다. 개입형은 사용자 직접 대화를 지원하는 팀원 또는 별도 세션을 사용한다.

코디네이터가 작업 경로의 셸에서 테스트를 실행한다. 팀의 작업 표시만으로 프로세스 종료를 추정하지 않고 세션 식별자·완료 계약을 확인한다. 팀 재개·종료 제한과 권한은 설치 버전 정책을 따른다. 서브 에이전트만 가능한 경우 작업공간 가시성·개입의 한계를 명시하고 전체 팀 수명주기를 실증했다고 주장하지 않는다.
